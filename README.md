# 温馨提示

两个可以在手机浏览器里直接打开的网页,不用安装任何东西。

- `/guanxin/` —— 只有关心话
- `/happy-birthday/` —— 关心话 + 生日惊喜

## 用法

打开页面 → 填名字(可选)→ 点「弹出提醒」→ 关心话铺满屏幕 → 自动消失 → 可以再来一次。

`happy-birthday` 那个页面在这之后还会突然出现生日动画,停留 10 秒后自动关闭。

**界面上看不出后面有生日**,就是一个惊喜。

## 链接里带名字

在链接后面加 `?name=名字`,打开就自动填好:

```
…/guanxin/?name=小明
…/happy-birthday/?name=小明
```

这样可以为不同的人准备不同的链接。

## 技术说明

- 纯 HTML + CSS + JavaScript,每个页面一个文件,零外部依赖,可离线运行
- 每轮 **52 张**,和电脑版一致。手机屏幕小放不下这么多,卡片之间会重叠 ——
  所以位置不是"随机撒点",而是**按均匀网格分配**,保证铺满整屏而不是挤成几团
- 生日动画用 Canvas 绘制:烟花粒子、撒花、手绘蛋糕、暖橙烛光
- 手机竖屏优先,适配刘海屏安全区域

## 开发

`_dev/` 里是开发期的验证脚本(不打进站点):

```sh
# 在真实浏览器里跑 JS 并取回结果,验证页面逻辑
node _dev/cdp-probe.js <页面地址> --expr "JSON.stringify({...})"

# 先执行一段 JS(比如手动推进 canvas 帧),再截图
node _dev/cdp-shot.js <页面地址> <输出.png> --expr-file _dev/_inject.js
```

这两个脚本用 Edge 的远程调试协议,能直接验证页面逻辑和 canvas 渲染,
比只靠截图可靠 —— 无头模式下 `requestAnimationFrame` 不触发、命令行截图也可能
抓不到 canvas,所以截图前要手动推进若干帧。
